# FindMe Campus Lost & Found System \- Frontend

## Overview

FindMe is a smart campus lost and found platform designed to help students, staff, and campus visitors recover lost belongings efficiently. The system provides lost item reporting, found item reporting, ownership claims, AI\-assisted matching, QR ownership tags, notifications, analytics, and administrative management features.

This repository contains the React frontend application that provides the user interface for the FindMe platform.

## Installation

Clone the repository:

git clone <repository\-url>Navigate into the project:

cd findme\-frontend

Install dependencies:

npm install

Run the application:

npm run dev

The application will be available at:

[http://localhost:5173](http://localhost:5173)
